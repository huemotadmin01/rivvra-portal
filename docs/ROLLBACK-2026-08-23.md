# Rollback plan — redesign → production

**Read the first line of each level, pick the smallest one that covers the
symptom, stop there.** Every level is independent; you do not need the ones
above it.

Production deploys from `main` via `.github/workflows/deploy.yml` on push.
**Any push to `main` is a deploy.** Recovery time is one build — roughly 2–4
minutes — for every level below.

---

## Level 0 — the flag (no deploy, instant)

**Covers:** anything on a V2 page — 160 pages, 171 routes.

Unset `uiV2` on the affected org. The route falls back to the legacy page
immediately, no build, no push.

**On day 1 this level does nothing**, because no production org has `uiV2` on.
It exists for the day you switch a pilot org over. If that day goes wrong, this
is the whole rollback.

---

## Level 1 — one import line (surgical, one build)

**Covers:** the 16 surfaces that ship live and are NOT flag-gated — the five
auth pages, the ten `/admin/*` pages, and Document Vault.

Every legacy original is still in the repo, unreferenced. **Verified present:
all 15 files, plus `DocumentVault.jsx`.** Rolling one back is a single import
edit in `src/App.jsx`:

```diff
- import OrgLoginPage from './pages/OrgLoginPageV2';
+ import OrgLoginPage from './pages/OrgLoginPage';
```

The local name is unchanged, so **no other line in the file needs touching**.

**This was rehearsed, not assumed** — the swap above was applied, built clean,
and reverted on 2026-08-22.

| symptom | line to change in `src/App.jsx` |
|---|---|
| Login page broken | `OrgLoginPageV2` → `OrgLoginPage` |
| Forgot-password broken | `ForgotPasswordPageV2` → `ForgotPasswordPage` |
| Reset-password broken | `ResetPasswordPageV2` → `ResetPasswordPage` |
| Find-workspace broken | `FindWorkspacePageV2` → `FindWorkspacePage` |
| Invite-accept broken | `InviteAcceptPageV2` → `InviteAcceptPage` |
| Document Vault broken | `DocumentVaultV2` → `DocumentVault` |
| Any `/admin/*` page broken | `admin/<Name>V2` → `admin/<Name>` |

```bash
git checkout main && git pull
# edit the one import in src/App.jsx
npm run build          # confirm it compiles before pushing
git commit -am "rollback: <page> back to legacy" && git push
```

## Level 2 — revert one commit (targeted)

**Covers:** the three legacy files that changed and are live today.

| symptom | commit to revert |
|---|---|
| Incentive amounts show the wrong currency symbol | the incentive currency-formatter commit |
| Aged Receivables rows duplicated or missing | the React-key fix |
| ATS application detail broken | the `applicationDetailParts` extraction (**large — prefer Level 3**) |

```bash
git checkout main && git pull
git log --oneline -- src/pages/incentive/MyEarnings.jsx   # find the sha
git revert <sha> && npm run build && git push
```

---

## Level 3 — revert the whole merge (last resort)

**Covers:** anything you cannot localise, or an ATS-application-detail failure.

```bash
git checkout main && git pull
git log --oneline -3                     # find the redesign merge commit
git revert -m 1 <merge-sha>              # -m 1 keeps main's side
npm run build                            # MUST pass before pushing
git push
```

`-m 1` is required — it is a merge commit, and `1` selects the pre-merge
`main` as the parent to keep.

**Note this does not lose the redesign.** It only removes it from `main`;
`redesign` still holds all 264 commits, and re-merging later is a normal merge.

---

## What rollback does NOT need to touch

- **No backend.** The API repo was not modified, and the redesign adds no new
  API calls — every endpoint it uses already existed.
- **No database.** No migrations, no schema or data changes.
- **No Render.** Staging is a separate service on the `redesign` branch and is
  unaffected by anything you do to `main`.

---

## Fast triage

| what broke | level |
|---|---|
| A V2 page, after `uiV2` was switched on | **0** — unset the flag |
| Login / password / invite / admin / vault | **1** — one import line |
| Incentive currency, Aged Receivables | **2** — revert one commit |
| ATS application detail, or anything unclear | **3** — revert the merge |
